> PLANNING §6 언어 확장 — 오프라인 회화 번들(`src/features/translate/phrases.ts`) 25문구 검수용.
> 안전 중요(Emergency·Hospital) 항목 우선. 수정 시 해당 시나리오의 언어 필드를 갱신.

## 검수 대상

2026-07-30 통역 언어 확장으로 추가된 언어 × 25문구.
원문(ko)은 기존 검증분이며, 상대(한국인)에게 보여주는 것은 ko 필드다.
각 언어 필드는 **사용자가 문장의 뜻을 이해하는 용도**이므로 격식체보다 자연스러운 구어를 택했다.

| 차수 | 추가 언어                                                 | 대역 수 |
| ---- | --------------------------------------------------------- | ------- |
| 1차  | vi · th · id · ms · fil                                   | 125     |
| 2차  | hi · bn · ne · ar · ru · mn · uz · fr · de · es · pt · it | 300     |
| 3차  | yue · tr · km · my · kk                                   | 125     |

기존 검증분(en/ja/zh-CN/zh-TW)을 합쳐 회화 대역은 총 26개 언어(통역 언어 27개 = 원문 ko 포함)다.
타갈로그어는 별도 코드를 두지 않고 필리핀어(`fil`)로 통합했다 — 같은 언어이며
`normalizeLang`이 `tl`을 `fil`로 흡수한다.

## 1. 정책 결정 항목 (원어민 확인 우선순위 ①)

개별 문구가 아니라 언어 전체에 걸리는 판단이다. 여기서 방향이 정해지면 다수 문구가 함께 바뀐다.

| #   | 언어  | 쟁점                    | 확정 정책 (Codex 교차 검증 반영)                                                                                                        | 원어민 확인 |
| --- | ----- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| P1  | th    | 종결 어미 ครับ/ค่ะ 생략 | **생략 유지.** 성별 어미라 앱이 사용자 성별을 모른다. 대신 명령조가 되는 문구는 `ขอ`·`ช่วย`·`หน่อย`로 정중함 보완                       | ⚠️ 필요     |
| P2  | vi    | 남부/북부 어휘 변이     | **안전 2건만 병기 유지.** `thịt heo (thịt lợn)`·`đậu phộng (lạc)` — 종교·알레르기 직결이라 시각적 번잡함보다 전국 이해가 우선           | ⚠️ 필요     |
| P3  | fil   | 경어 `po` 사용          | **상황별 분기로 변경.** 대면 요청에는 `po` 유지, 긴급 외침은 제거(`Tulong po!` → `Tulong!`)                                             | ⚠️ 필요     |
| P4  | id/ms | 두 언어 문구 유사성     | **동일 표현은 그대로 두되 핵심 어휘는 지역 표준 준수.** `polisi/polis`·`obat/ubat`·`kartu/kad`·`pengembalian pajak/bayaran balik cukai` | ⚠️ 필요     |
| P5  | fil   | 영어 차용어             | **유지.** `bill`·`card`·`check-out`·`password`는 실제 코드스위칭과 부합. 순화하면 오히려 낯설어짐                                       | ⚠️ 필요     |

P1·P3은 Codex 판정에 따라 정책을 조정했고(태국어 정중 보조어 추가, 필리핀어 po 상황별 분기),
P2·P4·P5는 기존 정책이 타당하다는 판정을 받아 유지했다.

## 4. 안전 중요 문구 전수 (원어민 확인 우선순위 ②)

Emergency·Hospital 시나리오는 오역 시 피해가 크다. 아래 8문구는 전수 확인 대상이다.

| #   | 원문(ko)              | vi                                    | th                        | id                               | ms                                | fil                               |

**⚠️ 상세 — 원어민 확인 최우선**

- **S2·S3 fil (모델 판단 불일치)**: Codex는 `Pakitawag po ng…`를 부자연스럽다며 `Tumawag po kayo ng…`를 제안했고(high), Claude는 `paki-` 접두사가 표준 정중 요청형이라 판단해 유보했다(§3.2 R2·R3). 안전 문구인데 두 모델이 갈렸으므로 **가장 먼저 확인**할 항목.
- **S2 vi**: 베트남에서 경찰은 통상 `công an`. 여기서는 한국 경찰을 가리키므로 국제 통용어 `cảnh sát`을 택했다. 베트남 화자에게 어느 쪽이 즉시 이해되는지 확인 필요.
- **S6 th**: `เจ็บ`(외상성 통증) vs `ปวด`(둔통). 병원에서 어느 쪽이 포괄적인지 확인 필요. Codex는 이 항목을 지적하지 않아 판단이 갈리지는 않았다.
